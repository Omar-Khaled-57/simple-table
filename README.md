# Simple Table

A responsive React + TypeScript web app for managing and printing exam result tables.

## Features

- Multiple editable tables with tabs
- Add/remove rows and columns, rename and resize columns
- Sort by name or grade
- Three table layouts (classic, soft, compact)
- Print/PDF export with per-table headers and statistics
- Arabic RTL interface with light/dark themes

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Lint

```bash
npm run lint
```
